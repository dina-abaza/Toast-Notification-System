# 🔔 Toast Notification System (JavaScript)

This is a simple project that displays **toast notifications** based on different messages (success, error, invalid). It uses **HTML**, **CSS**, and **JavaScript** to create dynamic, animated alert messages that disappear automatically.

---

## 🚀 Features

- ✅ Success, error, and invalid message types
- 🔄 Auto-dismiss after a few seconds (6s)
- 🎨 Smooth animation using `@keyframes`
- 🧠 Smart color detection based on message content
- 📦 Toast container supports multiple stacked messages

---

## 🛠️ Technologies Used

- **HTML** – Button structure and toast container
- **CSS** – Styling, animations, and color themes
- **JavaScript** – Dynamic toast creation and logic

---

## 💻 How It Works

1. User clicks a button to trigger a message.
2. JavaScript creates a new `div` with the `.toast` class.
3. The message is shown with a sliding animation.
4. A progress bar animates at the bottom.
5. After 6 seconds, the toast disappears automatically.
